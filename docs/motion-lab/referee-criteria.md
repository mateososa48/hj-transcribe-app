# Motion lab referee criteria

Frozen before implementation.

- The page exposes exactly ten named concepts.
- Replay restarts all ten experiments from their first frame.
- Pause freezes every animation and resume continues it.
- Speed offers 0,5×, 1×, and 2×.
- Reduced motion removes spatial travel while retaining a perceptible state indication.
- Every control is reachable and operable by keyboard with a visible focus indicator.
- Desktop, short-window, and narrow layouts have no horizontal document overflow.
- Controls and labels do not overlap and maintain at least 8 px visual separation.
- No console errors, failed runtime requests, or unexpected external requests.
- Exact German stage labels remain visible; color is not the only state signal.
