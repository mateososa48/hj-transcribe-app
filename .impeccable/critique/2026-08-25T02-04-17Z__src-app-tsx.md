## Priority issues

- **[P1] „Neu erstellen" silently overwrites his edits** — generate() replaces sections wholesale (src/lib/generate.ts:82–107); button has no confirmation (SessionView).
- **[P1] Crashed-recording recovery is a trap** — recovery offer only on start screen; the same session in the sidebar opens as an empty dead page; „Verwerfen" deletes audio in one click, no AlertDialog (StartScreen.tsx:54–65).
- **[P1] Interrupted pipeline dead-ends** — pipeline state is in-memory; after reload, transcript-done-but-no-notes shows "Noch keine Notizen" with no action (SessionView Notizen tab); Diktat shows nothing.
- **[P2] Session title font bug** — Input base `md:text-sm` overrides `text-2xl`: 15.75px instead of 27px on desktop (SessionView.tsx:154–163).
- **[P2] App violates its own size/contrast rules** — sidebar preview 13.5px @ ~3.7:1; timestamps 13.5px; Kopieren 31px; speaker buttons 27px; tabs 29px (rule: ≥40px routine targets, no text-xs).
- **[P2] Speaker styling misleads** — %2 alternation makes Sprecher 1 & 3 identical, Sprecher 2 gray (TranscriptView.tsx:85–89); "dot" comment refers to nothing.
- **[P2] Transcript and audio disconnected** — timestamps dead, Audio tab is a bare native element; SyncedPlayback pattern exists but only for Diktat.
- **[P2] Empty sections can't be filled** — no textarea when empty (SectionCard.tsx:119–123).
- **[P2] Kopiert feedback lasts 2.2s; copy is the smallest control on the page.**
- **[P2] Persistence nudge missing** — "Dauerhafte Speicherung: Nicht aktiv" only visible in settings.
- **[P3] Medikation columns ragged; "0:23 min" format; no year in dates; identical Termin/Diktat recorders; docx deps unused; PRODUCT.md/DESIGN.md stale vs rebuild; 50-session sidebar cap.**
